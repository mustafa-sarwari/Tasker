# Security Policy

## Supported Versions

We are committed to maintaining the security of Tasker. Currently, the following versions are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Tasker, please help us maintain the security of our users by following these guidelines:

### How to Report

1. **DO NOT** open a public issue for security vulnerabilities
2. Email security concerns to: mustafa.sarwari@example.com
3. Include the following information:
   - Type of vulnerability
   - Steps to reproduce the issue
   - Potential impact
   - Any suggested fixes (if applicable)

### What to Expect

- You will receive an acknowledgment within 48 hours
- We will investigate and provide updates on the resolution timeline
- Once fixed, we will notify you and credit your contribution (if desired)

## Security Best Practices

When using Tasker:

- **Browser Security**: Ensure you're using an up-to-date browser
- **LocalStorage**: Be aware that tasks are stored locally in your browser
- **Private Browsing**: Tasks will not persist in private/incognito mode
- **Shared Computers**: Clear your browser data if using a shared computer

## Known Considerations

- Tasker stores data in browser localStorage, which is accessible to JavaScript on the same domain
- No server-side storage or user authentication is implemented
- Tasks are visible to anyone with access to your browser

## Updates

We regularly review and update our security practices. Check this document periodically for any changes.

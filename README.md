# ✅ Tasker - Simple Task Management App

A clean and intuitive web-based task management application that helps you organize your daily tasks with ease. Built with vanilla JavaScript and designed for simplicity and efficiency.

> 📝 A lightweight to-do list app with persistent storage, making task management effortless and accessible from any browser.

---

## 🚀 Live Demo

[Click here to try Tasker](https://mustafa-sarwari.github.io/Tasker/)

---

## 🛠️ Built With

- 🧱 **HTML5** – semantic structure and markup
- 🎨 **CSS3** – modern styling with flexbox and responsive design
- ⚙️ **JavaScript (Vanilla)** – task management logic and localStorage API
- 🖋️ **Google Fonts** – custom typography for better readability

---

## 🎯 Features

- ➕ **Add Tasks** – Expanding textarea input for easy task entry
- 🗑️ **Remove Tasks** – Delete tasks with confirmation prompt to prevent accidents
- 💾 **Persistent Storage** – Tasks saved in browser localStorage and persist across sessions
- 📱 **Responsive Design** – Works seamlessly on desktop and mobile devices
- ⚡ **Lightweight** – No frameworks or dependencies, pure vanilla JavaScript
- 🎨 **Modern UI** – Sleek black and white theme with smooth hover effects

---

## 🧩 How to Use

1. Type your task into the textarea input field.
2. Click the **"Add"** button to add the task to your list.
3. Each task displays with a **"Remove"** button.
4. Click **"Remove"** to delete a task (with confirmation prompt).
5. All tasks are automatically saved to your browser and persist after page reload.
